# tgfind — поиск беговых чатов в Telegram

Находит публичные чаты по ключевым словам и выдаёт список ссылок
в файле. Каналы в список не попадают — они нужны только как путь к своим
чатам обсуждения. Работает от вашего аккаунта через официальный API Telegram.

**Только читает.** Не вступает в чаты, ничего не пишет, не собирает
участников — видит то же, что любой человек в поиске Telegram.

## Как чат попадает в список

Одно из четырёх:
- слово из `keywords.txt` есть в **названии**;
- слово есть в **описании**;
- в сообщениях чата слова встречались **больше 5 раз**;
- это **чат обсуждения подходящего канала**.

Канал подходит, только если слово есть в его названии или описании —
по счёту сообщений нет: в большом канале «бег» найдётся всегда. У
подходящего канала берётся его чат обсуждения и «похожие каналы»; те
тоже проходят проверку по названию и описанию, поэтому поиск не
расползается в случайные темы.

Если чат обсуждения закрытый (без ссылки), в список он не попадает —
писать туда можно только комментариями под постами канала. Сколько
таких нашлось, скрипт пишет в конце.

Где искать кандидатов:
1. поиск Telegram по каждой строке `queries.txt`;
2. ссылки `t.me/...` и `@имена` из описаний найденных чатов — клубы
   часто ссылаются друг на друга;
3. чаты обсуждения и «похожие каналы» подходящих каналов.

## Окно (проще всего)

Двойной щелчок по **`tgfind_gui.pyw`** — откроется окно без консоли.
Если не открылось: `python tgfind_gui.pyw`.

В окне:
- ключи API и телефон (при первом входе окно спросит код из Telegram,
  а если включена двухэтапная проверка — и пароль);
- **слева** — что вводить в поиск Telegram, по запросу на строку;
- **справа** — слова, по которым чат подходит (основа слова на строку);
- порог сообщений и минимум участников;
- «Начать поиск», «Остановить», «Открыть таблицу».

Всё введённое сохраняется: слова — в `queries.txt` и `keywords.txt`,
ключи и телефон — в `config.json`.

Поменяли слова справа — нажмите **«Начать заново»**: иначе уже
проверенные чаты не перепроверятся по новым словам.

## Первый запуск из командной строки

1. Установить библиотеку (один раз):

   ```bash
   python -m pip install -r requirements.txt
   ```

2. Получить ключи API: зайти на https://my.telegram.org → API development
   tools → создать приложение (название и описание любые). Понадобятся
   **api_id** и **api_hash**.

3. Запустить:

   ```bash
   python tgfind.py
   ```

   Скрипт спросит api_id и api_hash, затем телефон и код из Telegram —
   как при входе на новом устройстве. Больше спрашивать не будет.

## Результат

- `results.csv` — таблица для Excel: ссылка, название, число
  участников, почему найден, описание. От больших чатов к маленьким.
- `links.txt` — только ссылки, по одной на строку.

## Полезные ключи

```bash
python tgfind.py --min-members 100    # отсеять совсем маленькие
python tgfind.py --threshold 10       # строже: больше 10 сообщений со словами
python tgfind.py --export-only        # не искать, пересобрать таблицу
```

## Продолжение и повтор

Прогресс сохраняется в `state.json` после каждого чата. Если прервать
(Ctrl+C) или Telegram попросит долгую паузу, следующий запуск продолжит
с того же места. Новые строки в `queries.txt` ищутся, старые — нет.
Начать с нуля — удалить `state.json`.

## Если Telegram просит паузу

Это нормально: на частые запросы Telegram отвечает «подождите N секунд».
Скрипт ждёт сам. Открытие чатов по ссылкам из описаний Telegram
ограничивает строже всего, поэтому за запуск их открывается не больше 60
(`--max-resolve`), остальное — в следующий раз.

## Не публиковать

`tgfind.session` — это вход в ваш аккаунт, `config.json` — ключи API.
Никому их не отправляйте. В git они не попадают (`.gitignore`).

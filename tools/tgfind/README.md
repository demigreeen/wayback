# tgfind — поиск беговых чатов в Telegram

Находит публичные чаты и каналы по ключевым словам и выдаёт список ссылок
в файле. Работает от вашего аккаунта через официальный API Telegram.

**Только читает.** Не вступает в чаты, ничего не пишет, не собирает
участников — видит то же, что любой человек в поиске Telegram.

## Как чат попадает в список

Одно из трёх:
- слово из `keywords.txt` есть в **названии**;
- слово есть в **описании**;
- в сообщениях чата слова встречались **больше 5 раз**.

Где искать кандидатов:
1. поиск Telegram по каждой строке `queries.txt`;
2. ссылки `t.me/...` и `@имена` из описаний найденных чатов — клубы
   часто ссылаются друг на друга;
3. «похожие каналы», которые Telegram советует к подходящим каналам.

## Первый запуск

1. Установить библиотеку (один раз):

   ```bash
   python -m pip install -r requirements.txt
   ```

2. Получить ключи API: зайти на https://my.telegram.org → API development
   tools → создать приложение (название и описание любые). Понадобятся
   **api_id** и **api_hash**.

3. Запустить:

   ```bash
   python tgfind.py
   ```

   Скрипт спросит api_id и api_hash, затем телефон и код из Telegram —
   как при входе на новом устройстве. Больше спрашивать не будет.

## Результат

- `results.csv` — таблица для Excel: ссылка, название, чат или канал,
  число участников, почему найден, описание. Сначала чаты, потом каналы,
  внутри — от больших к маленьким.
- `links.txt` — только ссылки, по одной на строку.

## Полезные ключи

```bash
python tgfind.py --only чат           # только чаты, без каналов
python tgfind.py --min-members 100    # отсеять совсем маленькие
python tgfind.py --threshold 10       # строже: больше 10 сообщений со словами
python tgfind.py --export-only        # не искать, пересобрать таблицу
```

## Продолжение и повтор

Прогресс сохраняется в `state.json` после каждого чата. Если прервать
(Ctrl+C) или Telegram попросит долгую паузу, следующий запуск продолжит
с того же места. Новые строки в `queries.txt` ищутся, старые — нет.
Начать с нуля — удалить `state.json`.

## Если Telegram просит паузу

Это нормально: на частые запросы Telegram отвечает «подождите N секунд».
Скрипт ждёт сам. Открытие чатов по ссылкам из описаний Telegram
ограничивает строже всего, поэтому за запуск их открывается не больше 60
(`--max-resolve`), остальное — в следующий раз.

## Не публиковать

`tgfind.session` — это вход в ваш аккаунт, `config.json` — ключи API.
Никому их не отправляйте. В git они не попадают (`.gitignore`).

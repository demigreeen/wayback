# WayBack

Сайт, который превращает архив экспорта тренировок в анимированное видео
всей спортивной истории на карте. Точки тренировок вспыхивают в
хронологическом порядке, камера летит за ними, в финале отдаляется и
показывает всю картину разом.

**[wayback.pro](https://wayback.pro)**

Работает целиком в браузере: у сайта нет сервера. Распаковка архива, разбор
треков и рендер видео выполняются на компьютере пользователя — геоданные
никуда не отправляются. На карте показывается не место старта тренировки,
а точка дальше по маршруту, чтобы в кадр не попадал домашний адрес.

---

## Запуск у себя

```bash
python -m http.server 8123 --directory site
```

Открыть `http://localhost:8123`. Кнопка «Посмотреть демо» строит
синтетическую историю из 84 тренировок — реальный архив не нужен.

Тестовые архивы (Strava, Garmin, Huawei, одиночный GPX):

```bash
python tools/make_testdata.py
```

Ключ `--big` добавит архив Strava на 300 тренировок — размер и плотность
точек как в живой выгрузке; `--stress` — архив на 2500 тренировок
с 200 МБ постороннего груза для проверки памяти.

---

## Что поддерживается

| Источник | Что внутри архива |
|---|---|
| Strava | bulk export: `activities/*.gpx.gz`, `*.fit.gz`, `*.tcx.gz` + `activities.csv` |
| Garmin | GDPR-архив с вложенными ZIP и FIT-файлами |
| Huawei | выгрузка Privacy Center: `motion path detail data.json` |

Формат определяется по сигнатуре файла, а не по расширению. Вложенные
архивы и gzip разбираются рекурсивно, дубликаты отсеиваются.

## Структура

```
site/                  сайт (публикуется на GitHub Pages)
  index.html           лендинг + разметка плеера
  css/app.css          белая тема лендинга, тёмная — плеера
  js/parse.js          разбор: ZIP, GZ, GPX, TCX, FIT, CSV, Huawei
  js/player.js         движок анимации, ориентации, подписи, экспорт
  js/vectormap.js      свой рендер карты из векторных тайлов OSM
  js/cities.js         города GeoNames для подписей (генерируется)
  js/app.js            приём файлов, прогресс, фильтры, демо
tools/                 генераторы тестовых данных и датасета городов
legacy/                прежнее десктопное приложение на Python
```

Публикация настроена через GitHub Actions: коммит в `main` — и сайт
обновляется.

## Технологии

Ванильный JavaScript, без сборщика и без npm. Все библиотеки лежат
локально в `site/js/vendor/`.

- **Leaflet** — интерактивная карта для пауз и перемотки
- **Собственный canvas-движок** — анимация и покадровый рендер
- **fflate** — чтение ZIP через центральный каталог, с поддержкой
  дескрипторов данных и ZIP64
- **Свои парсеры** FIT и Huawei HiTrack
- **WebCodecs + mp4-muxer** — экспорт MP4, вертикально 1080×1920
  или горизонтально 16:9

Карта рисуется своим движком из векторных тайлов OpenStreetMap: разбор
protobuf и отрисовка в канвас написаны здесь же. Это нужно, чтобы готовый
кадр был собственным произведением по лицензии ODbL — тайлы попадают
в скачиваемое видео, а у хостингов карт это отдельный лицензионный пункт.

# legacy — десктопное приложение (версия 8)

Предыдущая версия проекта: Windows-приложение на Python, которое забирало
пробежки из Garmin Connect и собирало `animation.html`.

Работает как раньше — `run.bat` использует относительные пути и запускается
двойным кликом прямо из этой папки. Оставлено как рабочий инструмент
и как справочник по движку анимации.

Актуальная версия проекта — сайт в каталоге `site/`.

| Файл | Назначение |
|---|---|
| `app.py` | GUI на tkinter: установка библиотек, логин, MFA, журнал |
| `fetch_runs.py` | Выгрузка из Garmin Connect, дедуп по activityId |
| `build_animation.py` | Генератор `animation.html` (JS-движок внутри как шаблон) |
| `run.bat` | Запуск двойным кликом |
| `example_preview.html` | Собранное превью на синтетических данных |

Ограничение, из-за которого проект переехал на сайт: неофициальный доступ
к Garmin Connect блокируется Cloudflare по TLS-отпечатку и периодически
ломается. Загрузка файлов экспорта работает всегда.
